## 4. Rechte anzeigen
Grants for anna@127.0.0.1
GRANT `auswertung` TO `anna`@`127.0.0.1`
GRANT USAGE ON *.* TO `anna`@`127.0.0.1` IDENTIFIED BY PASSWORD '<Hash>'
SET DEFAULT ROLE `auswertung` FOR `anna`@`127.0.0.1`
Grants for auswertung
GRANT USAGE ON *.* TO `auswertung`
GRANT SELECT ON `shop`.* TO `auswertung`
(Die Fehlermeldungen nennen den Host als 'localhost': der Server löst 127.0.0.1 in einen Namen auf. Das Konto 'anna'@'127.0.0.1' hat trotzdem gepasst.)
