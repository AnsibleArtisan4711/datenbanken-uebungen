## 4. PostgreSQL-Cluster (Debian-Verwaltung mit pg_lsclusters)
$ pg_lsclusters
Ver Cluster Port Status Owner    Data directory              Log file
16  main    5432 down   postgres /var/lib/postgresql/16/main /var/log/postgresql/postgresql-16-main.log

## 5. Eine MariaDB-Instanz starten und das Prozessmodell ansehen
MariaDB: ein Prozess (PID vorhanden: ja), Threads: 13 (Wert variiert)

## 6. Einen PostgreSQL-Cluster starten und das Prozessmodell ansehen
PostgreSQL: Hauptprozess plus Hilfsprozesse:
  autovacuum launcher 
  background writer 
  checkpointer 
  logical replication launcher 
  walwriter 
$ pg_lsclusters
Ver Cluster Port Status Owner    Data directory              Log file
