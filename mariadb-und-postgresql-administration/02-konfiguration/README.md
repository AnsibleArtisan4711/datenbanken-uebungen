# 02 Konfiguration

| Datei | Zweck |
|---|---|
| `02.1-konfiguration.md` | Die Übung mit Aufgaben, Kontrollfragen und Musterlösung |
| `beispiel_mariadb.cnf` | Erfundene Beispielkonfiguration (MariaDB) mit absichtlichen Schwächen |
| `beispiel_postgresql.conf` | Erfundene Beispielkonfiguration (PostgreSQL) mit absichtlichen Schwächen |
| `konfig_pruefen.py` | Prüft eine Konfigurationsdatei (MariaDB .cnf oder postgresql.conf) auf riskante Einstellungen. |
| `konfiguration.sh` | Konfigurationsdateien, Rangfolge und Änderungen im laufenden Betrieb (MariaDB und PostgreSQL). |
| `lauf.sh` | Skript |
| `beispiele/konfiguration.ausgabe.txt` | Echte Ausgabe des Laufs von `konfiguration` |
| `beispiele/lauf.ausgabe.txt` | Echte Ausgabe des Laufs von `lauf` |
