## Aufgabe

### Aufgabe 1 – Begriffe zuordnen (Einheit 7.1)

Zeichnen Sie Auftrag, Schritte, Zeitplan und Operator in einem Bild und beschriften Sie.

### Aufgabe 2 – Aufträge auswerten (Einheit 7.2)

Führen Sie `python3 agent_jobs.py beispiel_jobs.csv` aus und erklären Sie die nächsten Läufe und Hinweise.

### Aufgabe 3 – Auftrag anlegen (Einheit 7.3)

Erklären Sie die Aufrufe in `beispiel_agent.sql` und legen Sie den Auftrag auf `sql01` an (nicht in diesem Material geprüft).

### Aufgabe 4 – Benachrichtigung (Einheit 7.4)

Legen Sie fest, wer bei einem Fehler des Auftrags „Protokollsicherung“ benachrichtigt wird und wie die Benachrichtigung versendet wird (nicht bestätigt).

## Hinweise

- Die Aufträge der CSV sind erfunden; das Skript berechnet nur die nächsten Zeitpunkte (Annahme: heutiges Datum 20.11.2026, 08:15).
- Die Prozedurnamen und Parameter in der `.sql`-Datei stammen aus Fachwissen; **nicht bestätigt, nicht ausgeführt**.

## Kontrollfragen

2. Was ist ein Operator?
3. Warum wird ein deaktivierter Auftrag trotzdem aufgelistet?
4. Warum sollten Aufträge unter einem Konto mit minimalen Rechten laufen?

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

1. Ein Auftrag hat Schritte und einen oder mehrere Zeitpläne; bei Fehlern informiert er einen Operator.
2. Siehe `beispiele/lauf.ausgabe.txt`: Vollsicherung Sonntag 22:00; Differenz heute 22:00; Protokollsicherung stündlich ab 09:15 ohne Benachrichtigung; Konsistenzprüfung Samstag 23:30; deaktivierter Importjob.
3. `sp_add_job`, `sp_add_jobstep`, `sp_add_jobschedule`, `sp_add_jobserver` (Fachwissen, nicht geprüft).
4. Beispiel: Operator mit der E-Mail-Adresse einer Verteilerliste; Versand über die Mail-Funktion des Servers (Einrichtung nicht bestätigt).

**Kontrollfragen (Antwortskizzen):**

1. Sonst bleibt ein Ausfall (z. B. der Sicherung) unbemerkt.
2. Ein Empfänger für Benachrichtigungen (Fachwissen, nicht bestätigt).
3. Sie belegen noch Zeitpläne und könnten versehentlich wieder aktiviert werden; sie gehören geprüft oder gelöscht.
4. Ein Fehler oder Missbrauch hätte begrenzte Auswirkung.

</details>
